# 八奈见皮肤与适中信息密度

## 本轮布局原则

默认视图只承担当前任务；解释、配置和诊断按需展开。不是缩小字号、压缩间距，也不是删除功能。

- **全局导航**：四个功能分区，默认显示当前分区的入口。搜索覆盖全部分区；分区切换不触发页面跳转，实际导航仍通过既有守卫。收起侧栏后保留全部入口。
- **问答**：一条引导、两个可直接使用的问题示例、主要输入区。更多示例通过“换一组”查看；回答依据流程默认收起。手机和短屏桌面保持输入区可达。
- **文档**：默认全宽列表，保留搜索、状态筛选及错误提示。原来的固定筛选侧栏和统计卡片移入“筛选与概况”，筛选生效时保留提示，不改筛选 URL 和请求契约。
- **知识库资源**：标题只出现一次；中文页签帮助用户定位。权威版本、所属工作区和发布事实继续在原有详情抽屉中读取，未知与不可用状态仍在默认视图提示。
- **任务中心**：任务列表优先，异常任务、陈旧状态、高风险对账与权限保持可见。运行摘要、生命周期、保存视图和对账诊断默认收起。多个读取失败汇总到同一提示区，避免重复告警占满首屏。

## 皮肤边界

`styles.css` 中的 `html[data-theme="anime"]` 继续提供语义色；`theme/anime.css` 只负责皮肤装饰和已核验素材，不重新定义业务成功、失败或危险状态。亮色、暗色、八奈见仍是三个独立选项，沿用原有偏好存储。

主视觉限于欢迎页；文档表格、任务列表不叠加人物、漂浮装饰或背景图片。移动端省略大型立绘，保留品牌缎带及海蓝语义色。遵循减少动态效果设置。

## 素材依据

素材审计见 `frontend/public/themes/yanami/README.md`，含来源路径、源码引用点和 SHA256。

- 导航 SVG 使用 WeKnora 当前菜单实际加载的 `frontend/src/assets/img/` 文件。
- 品牌缎带 SVG 使用已挂载组件实际引用的 theme materials 文件。
- 人物文件是 WeKnora `AnnaWelcome.vue` 实际导入的生产 `iridescent-character.png`，不是预览图。没有把 docs 目录的 SVG 母版或历史预览资产作为页面素材。
- 缺少生产引用证据的旧主题图标不再被新皮肤引用；保留旧文件，避免删除既有工作。
